# Security

This is a private, unofficial maintenance project. Report issues privately to the repository owner. Do not attach account configuration, cookies, tokens, proxy passwords or raw authenticated responses.

DPAPI CurrentUser protects data at rest but is not a sandbox. Keep backups offline and use a separate test account. Check dependencies before rebuilding, verify hashes, and review changes before running binaries. Local npm audit results describe known npm advisories at the time of scanning, not all Go, browser or application risks.
