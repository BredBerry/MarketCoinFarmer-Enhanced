MARKET COIN FARMER V3 — сборщик с проверкой npm-зависимостей

1. Распакуйте весь архив. Запустите BUILD.bat без прав администратора.
2. Используются уже установленные Git, Go, Node, Wails beta.5 и Task.
3. Сборщик сохраняет исправления V2 и обновляет npm lock-файл через npm audit fix
   --package-lock-only --ignore-scripts, без --force. Затем npm ci.
4. Сборка продолжится только при нулевом общем и production npm audit.
   После сборки аудит повторяется, выполняются go mod verify и TestMCF.
   Если аудит не нулевой, сеть недоступна или тесты не проходят, сборщик
   остановится. Никаких принудительных обновлений и замены старого EXE.
5. Закройте ВСЕ окна Market Coin Farmer перед переносом настроек.
   Если окно осталось, сборщик повторяет запрос (Q отменяет установку).
6. Новая папка Market Coin Farmer - V3 <дата> создается отдельно на рабочем столе.
   Запустите EXE и проверьте аккаунт. Старая версия не удаляется.

По умолчанию импортируется текущая зашифрованная конфигурация из:
D:\Desktop\Market Coin Farmer - Improved 20261127-002306-e6c38a
Если папка переименована, запустите из CMD:
BUILD.bat -LegacyFolder "полный путь к работающей папке V2"
BUILD.bat -NoImport — чистая установка без аккаунтов.
DPAPI используется в контексте текущего пользователя Windows.

Отчеты, обновленный lock-файл и исходники: %LOCALAPPDATA%\MCFBuilder\<id>.
Если сборщик остановился, пришлите npm-audit-all.json и текст ошибки.
Не присылайте config.dpapi, config.yaml, cookies или пароли.

Ограничения: автоматическое исправление не гарантирует наличие совместимых
версий в npm. Проверка npm не заменяет аудит Go, WebView2 и самого EXE.
Скрипт V3 не запускался на Windows в среде автора. Сборка V2 проверена ранее
на компьютере пользователя. Никаких гарантий будущих API или отсутствия банов.
